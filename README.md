# Birdy

一款本机运行的 Mac 英语精读工具。在 Chrome/Safari 网页或 PDF 中选中文字后，按 **⌘4** 直接精读选中的文字；没有选中文字时，按 **⌘4** 进入截图框选。Birdy 优先读取辅助功能选区；浏览器未暴露选区时，通过当前阅读应用的复制功能读取，并恢复原剪贴板。需要在系统设置中允许 Birdy 的辅助功能权限。辅助功能选区和复制均未取得文字时，进入截图框选。

网页来源的精读便签覆盖在原页面上，记录自动保存；点击页面其他位置收起便签，点击便签打开 Birdy 对应的精读记录。PDF 来源打开 Birdy 记录窗口。需要截图时，单独点击应用里的“框选精读”或菜单栏的“截图框选精读”。

## 本机运行

需要 macOS 15.2 或更新版本。当前仓库可用 Swift Command Line Tools 构建：

```sh
make app
open dist/Birdy.app
```

启动应用时默认显示主窗口，并在 Dock 和菜单栏保留入口。关掉窗口后，可以点击 Dock 图标、再次双击应用或点击菜单栏里的“打开单词本”重新显示窗口。可在设置中关闭“启动应用时显示主窗口”。首次框选会请求“屏幕录制”权限；在系统设置 → 隐私与安全性中允许后重启应用。读取 Chrome 当前标签网址可能单独请求“自动化”权限。

在“设置”中填写兼容 Chat Completions 的 API 基础地址、模型名与自己的 API Key；默认填写 DeepSeek 官方 API 地址和 `deepseek-flash` 模型，仍需你自行提供可用的 DeepSeek API Key。Trae 中选择同名模型并不意味着 Birdy 可以使用 Trae 的额度或读取其密钥。API Key 存入 macOS 钥匙串。云端请求发送识字文字和后续追问，不上传截图或 PDF 文件。没有 Key 时截图和识字仍能使用，填写后可在记录中手动生成或重试精读。

在“预览”里截图 PDF 后，到对应精读记录中选择原 PDF 并核对页码。需要精确回到某句话时，在工具打开的 PDF 窗口里选中该句，再点“保存 PDF 选区”。扫描 PDF 无可选文字时仍可保存页码和截图。原 PDF 不会复制进应用；文件移动后可重新关联。

单词本支持搜索、修改、标记、删除和 CSV 导出。“完整备份 ZIP”包含精读记录、词条、对话和截图，不含 API Key 或 PDF 原文件。设置中可选择登录时启动。

## 验证与发布

```sh
sh Tests/run.sh
```

该检查覆盖批注与原文匹配、网页原句链接、记录重载和备份生成。可选地把一张含 `quietly redrawing` 的英文截图路径传给脚本，另验收真实 Vision 识字定位。

本机 `make app` 使用登录钥匙串中的固定 `Birdy Local Signing` 证书签名，反复重建时保持相同签名身份。该本地自签名证书只用于这台 Mac 上的开发测试；正式公开分享前，仍需使用 Apple Developer ID 签名并完成公证。此电脑尚未安装完整 Xcode；实际屏幕权限、快捷键、Chrome 自动化和真实模型服务仍需在交互环境中验收。

## 导航与表达

主导航为“阅读、积累、表达”。阅读收纳原文与精读记录，积累收纳单词本与句式库；第二层采用文字切换，不再使用蓝色底框。顶栏四项统一为搜索、框选、设置、Birdy 小鸟图标；小鸟打开学习指南，悬停保留功能提示，设置支持 ⌘,。

“表达”按既有话题分类管理整篇文章。已内置本次电车文章的 24 段全文论证树：先看中文，用英文自行表述，再点击段落查看英文原段，或一键切换全部语言。目录与原文段号便于核对全文覆盖；词句复述已移除，停止后台生成复述提示。旧词条兼容字段保留，不影响已有收藏。左侧集中话题筛选、文章列表和网页导入，右侧显示选中文章；结构目录收进文章工具栏菜单。

左侧文章库底部可以粘贴网页链接，点击“读取全文”。先核对抓取的正文首尾，再使用设置中配置的模型翻译完整段落并整理论证关系；英文始终来自实际取得的正文。受登录、订阅或网页结构限制不能直接读取时，可以粘贴完整英文正文继续。若译文或论证编排未覆盖全部段落，不会将不完整结果加入文章库。

文章独立保存到 ~/Library/Application Support/Suibiancha/article-practice.json，按话题筛选和标题切换；已有链接会直接打开，避免重复解析。ZIP 完整备份包含文章库，不包含 API Key。源码中的 Resources/ArticlePractice/article-data.json 是本次内置文章，make app 将其打入应用，打开内置文章不依赖 localhost 浏览器。

## 话题分类

精读自动生成一个主主题和最多两个具体话题。精读记录和单词本支持按主题筛选，点击话题标签即可修改。词条默认继承来源记录分类，手动改过的分类不会被自动覆盖；CSV 和 ZIP 备份包含分类。配置 API Key 后，启动或打开精读记录时后台为旧记录补分类（仅发送原文文字）；失败时保留记录，下次重试。

记录和词条的数据修改支持 ⌘Z 撤回、⇧⌘Z 重做，保留当前启动期间最近 100 组操作。删除记录后的截图文件保留在本地，供撤回恢复。话题编辑弹窗提供“恢复自动分类”；精读记录恢复模型分类，词条恢复来源记录分类。原文卡片与精读侧栏日期使用 yyyyMMdd，卡片元信息显示具体话题而非来源应用。

在精读记录的原文中选中词语，点击浮出的单词本按钮，会同时保存词条并在下方补充语境解读、普通说法对比和使用提示。生成期间显示进度；已保存的词条也可再次点击补充解读，已有观察不会重复添加。

## 原文表达关联

在单词本中点击词条标题，展开局部表达图；点击周围节点可查看两处原句、含义区别及来源，也可继续以该表达为中心探索。只识别同一链接或同一 PDF 的已摘录文字，没有来源的记录仅在该段内识别。不会抓取整篇网页，也不会生成原文没有的词。每个表达都会在本机核对原文位置，简单指代（如 these experiences、such adversity）不进入图谱。模型区分近义表达与语境改述，不把普通同话题、上下位关系当成近义词；语义判断仍可出错，可隐藏不合适的关联，或恢复隐藏关联。

首次启动自动为历史摘录补建关联，之后只处理新增或原文变化的来源。单词本顶部显示进度、失败及“刷新表达关联”入口（重新检查全部来源）。刷新前自动创建 ZIP 备份；新增 expression-links.json 保存关联、原句依据和隐藏记录，完整备份包含此文件。刷新不修改原有精读和收藏词条。原文修改或来源变化后，旧关联立即失效，后台重新识别；失败的来源可重试。命令行参数 --refresh-expression-links 可强制重建，expression-refresh-status.json 记录批次完成情况。

## 句式库

按既定14类积累写作结构。每条只展示简短核心句式、灰色原句和“回到精读记录”。不展示解读、语法拓展、复制、打开原文或隐藏操作；右上角保留与单词本相同的编辑和删除图标。编辑可修改核心句式及分类，原句保留溯源；删除支持 ⌘Z 撤回和 ⇧⌘Z 重做，个人编辑与删除记录不会被后台刷新覆盖。原句只来自已保存摘录，骨架只提炼原句中最小可迁移结构，例如 `[现象] driven by [原因]`、`The reason for [现象] is that [原因]`；不会给整段原文逐项挖空。固定措辞须能在原句中核对。

首次启动自动将历史句式重新提炼为短结构，新增或修改摘录后增量更新；顶部支持搜索和手动刷新历史。刷新前自动备份，失败不覆盖已成功保存的同源结果。句式保存在 sentence-patterns.json，完整备份包含该文件；sentence-pattern-refresh-status.json 保存批次结果。命令行参数 --refresh-sentence-patterns 强制重建。

例句在句式库、单词本、关联图中使用统一排版：展示时合并 OCR/复制遗留的单行换行，保留空行分隔的段落，随当前宽度自动折行。仅调整展示，不改动摘录、例句原文或批注定位。

句式库正文随窗口宽度展开，不设置固定正文最大宽度；窄窗口收紧分类侧栏和内边距，句式与例句自然折行，编辑和删除按钮保持可见。

## 框选后返回 Birdy

从 Dock 或应用切换器回到 Birdy 时，主窗口会从隐藏或最小化状态恢复，并回到当前桌面。恢复会取消尚未结束的框选呈现；较晚完成的识别结果仍保存，但不会再次隐藏主窗口或把焦点送回网页。正常框选和网页精读浮层保持原有行为。
