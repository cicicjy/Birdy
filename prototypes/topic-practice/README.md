# Birdy 全文论证树

当前版本按全文正文制作，不再选择部分句子。依据保存的 inkl 全文回读，正文有 24 段、934 个以空格分隔的英文词；图注、图片署名、站点导航与推广不计入正文。

## 全文与原文保护

- 24 个正文段落各出现一次，按照中心问题及七个论证层次编排。
- 每个节点展示完整段落中文译文、论证功能及原文段号；点击显示对应完整英文原段，再点击恢复中文。
- 七个层次下的短解释由本工具整理，与有段号的作者原文明确分开。
- 英文直接从 source-readback.txt 提取，保留原始措辞、英式拼写、标点及语病，不润色、不删去过渡句或解释。
- 顶部支持全文统一中英切换；左侧目录可定位论证层次，页末“原文段落覆盖”可按原顺序定位全部 24 段。
- 同一段只纳入一个节点，按论证关系归组，因此第 18 段与数字体验论据放在一起；段号始终保留原文顺序。

作者 Svetoslav Georgiev，来源 The Conversation；英文版本为 inkl 转载。Tech Xplore 同文注明 Creative Commons 转载许可，article-data.json 保存许可说明页面链接。未发布公共网站；只在本机提供学习页面。文中数字、代际概括及研究结果属于作者陈述，没有独立验证其援引研究。

- 品牌 18、分区 15、中文标题/正文/控件 13、辅助 12、元信息 11；英文参考 Georgia 15，来源标题 Georgia 13。
