| 页面 | 布局变化 | 保留的操作 |

## 验证证据与边界

- release 构建、应用打包、本机签名通过。
- Tests/run.sh 六组通过，覆盖导入、来源证据、句式、阅读持久化与撤回、文章覆盖及窗口意图。
- 代码对照确认原有操作处理函数保留；新增共享组件只处理展示与筛选，不修改存储层或模型服务。
- 在独立原生预览应用上使用数据副本检查约1080和820pt窗口，四页布局、原文话题筛选、精读搜索与自动选择、单词本更多菜单、回忆模式及单张揭晓可用。正式Birdy初次启动因钥匙串授权等待，用户完成授权后已可读取正式界面。
- 预览不加载凭据，模型相关操作未调用真实服务；截图中的缺少API Key提示属于预览环境，不代表正式配置丢失。
- 视觉检查发现原文网格默认垂直居中，使不同长度的卡片顶部不齐；改为顶部对齐。窄窗下搜索框收缩，正文自然折行，编辑/删除与追问保持可见。
- 最后一轮三项修正（顶部对齐、空结果文案、错误颜色）的正式应用已重新构建并校验签名。用户完成最终构建的钥匙串授权后，正式Birdy成功启动；四页切换、实际内容载入与主要操作入口已确认。原文网格顶部对齐已在正式宽窗口截图中确认；最终截图保存在本机 artifacts/ui-refinement-after/*-final.png。本次确认没有再次重建应用。
- 自动检查不等于逐个功能都做过真人端到端验收；本轮没有实际执行删除、导出、付费模型刷新或改动PDF关联。
