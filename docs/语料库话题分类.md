# 语料库话题分类

用于整理阅读摘录、精读记录、单词以及生活素材。先用稳定的大主题归类，再逐渐积累具体话题；一份素材可以服务于多个具体话题。

| 主题 | 可以积累的具体话题 |
|---|---|
| 运动与身体 | 跑步、力量训练、徒步、运动习惯、身体感受、恢复与休息 |
| 美食与烹饪 | 日常做饭、餐厅探店、地方饮食、咖啡与茶、食材、一个人的吃饭 |
| 阅读与文化 | 读书摘录、书评、文学、电影、音乐、展览、作品带来的思考 |
| 购物与消费 | 好物体验、购买决策、踩坑记录、性价比、品牌观察、二手与闲置 |
| 居住与日常 | 家居布置、收纳、生活用品、家务、租房、理想的生活空间 |
| 旅行与城市 | 旅行见闻、城市漫步、街区、自然风景、本地生活、人与地方的关系 |
| 关系与情绪 | 朋友、亲密关系、家庭、独处、社交、情绪变化、沟通 |
| 学习与成长 | 学习方法、语言学习、技能练习、习惯养成、注意力、自我认识 |
| 工作与职业 | 工作经历、职业选择、协作、效率、个人项目、工作的意义 |
| 科技与社会 | AI、数字生活、教育、环境、社会现象、技术对生活的影响 |
| 金钱与生活选择 | 日常开支、储蓄、收入与生活方式、时间和金钱的取舍 |

## 使用方式

- 默认自动分类，觉得不合适时再手动修改。
- 精读记录选一个主主题，搭配最多两个具体话题；单词继承来源段落的话题。
- 手动修改的分类保留，不被自动分析覆盖。
- 主题与素材类型分开：同一话题可以包含文章摘录、个人经历、照片、产品体验和随想。
- 暂时无法判断的素材放入“待分类”，以后再整理。

本表保留讨论时的“美食与烹饪”名称；Birdy 当前使用“美食与饮食”，涵盖食品添加剂、食品监管等更广的内容。
